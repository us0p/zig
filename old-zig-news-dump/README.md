# old-zig-news-dump
Public articles posted to the first iteration of zig.news

All articles that were public when zig.news was deleted are saved in `articles.csv`.
All images referenced in blog posts are under `images/`.

Copyright resides with the respective authors, this backup is offered only to allow
original creators to re-upload their content elsewhere.

This backup will stay up for a limited amount of time, after which it will be deleted.
